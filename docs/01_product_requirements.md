# 01. 要件定義

## 1. 背景

生成AIや画像AIで漫画背景風に変換した画像は、出力サイズが2000px程度で止まることが多い。漫画原稿では印刷解像度、見開き、背景拡大、パース定規への貼り込みなどでさらに大きな画像が必要になる。単純なバイキュービック、Lanczos、ニアレストネイバーでは、斜め線・曲線・建築物の輪郭・柵・窓枠・電線などにジャギやガタつきが出やすい。

本ツールは、白地に黒線の漫画背景線画を対象に、線画の見た目を保ちながら高解像度化する。

MVPの確定スコープは `docs/00_mvp_scope.md` を正とする。

## 2. 対象ユーザー

- 漫画家
- アシスタント
- 背景素材制作担当
- ローカルで画像処理を完結させたい制作者

## 3. 入力

MVPで扱う入力は以下とする。

- PNGを主対象にする
- JPEG/TIFFは読み込み対応候補だが、MVPの品質基準はPNGで確認する
- WebPは後回し
- RGB、RGBA、グレースケール画像
- 想定サイズは短辺1000px以上、長辺2000px前後
- 内容は白地に黒線の漫画背景線画
- RGBA入力は白背景に合成して処理し、MVPの最終出力はアルファなしPNGを既定とする

反転素材は `--invert` で白地黒線相当に変換して扱う。黒ベタ背景に白線が乗る複雑な素材はMVPでは正式対応しない。

MVPでは、ハッチング、カケアミ、点描、網点トーン、トーンとしてのグレー階調を品質保証対象にしない。薄いグレーは白へ飛ばし、十分暗い画素だけを線として扱う。

元写真そのものを漫画背景化する機能はスコープ外とする。

## 4. 出力

- PNG 8bitグレースケール
- PNG 16bitグレースケールは後続の優先対応
- TIFFは後回し
- デバッグ用中間レイヤーPNGはオプション
- 設定ファイルと処理ログ

MVPの主出力は最終PNG 1枚とする。レイヤー分離出力は将来対応とする。

## 5. 目標品質

優先順は以下だ。

1. 線のジャギが目立たない
2. 線がガタつかない
3. 元画像の線幅を忠実に保つ
4. 線が溶けない
5. 細い建築線、柵、窓枠、電線が消えない
6. 漫画原稿でのシャープさと二値化耐性を保つ
7. 処理がローカルで再現可能
8. 2x/3x/4x/6x/8xで品質を確保する

写真的ディテールや新規描き足しは優先しない。

## 6. 非目標

以下はMVPではやらない。

- 教師あり学習
- 独自ニューラルネットワーク学習
- Webサービス連携
- 画像生成AIそのものの呼び出し
- カラー漫画背景への最適化
- グレー階調・トーンの保持
- 黒ベタ背景の複雑な反転素材への最適化
- GUI
- CSP/Photoshopプラグイン
- 自動パース補正
- 自動線画化
- 著作権確認や素材ライセンス管理

## 7. ハードウェア前提

- RAM: 128GB
- VRAM: 8GB
- 家庭用Windows PCを主想定
- NVIDIA/AMD/Intel GPUいずれも考慮
- CUDA前提にはしない
- Vulkan対応のncnn系アップスケーラーを優先する

128GB RAMがあるため、Python側の画像配列処理は比較的余裕がある。一方、VRAM 8GBでは超解像モデルの一括処理が詰まる可能性があるため、外部アップスケーラーのtile-size設定を必須にする。

## 8. 基本方針

### 8.1 既定パイプライン

```text
入力
  → グレースケール正規化
  → 線画マスク抽出
  → 線画マスクをSDFで高解像度線アルファ化
  → 白キャンバスに黒線を合成
  → 出力
```

### 8.2 元案からの変更点

元案の「Real-CUGANで全体を拡大」は比較用としては有効だが、既定にはしない。理由は以下だ。

- Real-CUGAN側で線が微妙にうねることがある。
- その上からSDF線を合成すると線が二重に濃くなることがある。
- 細線がReal-CUGAN側で消えたり太ったりすると、合成結果の予測が難しくなる。

このリスクはグレー階調やトーン対応時に重要になる。MVPでは純線画を対象にするため、既定では外部アップスケーラーを使わず、線はSDFで再描画する。`tone_source` と外部アップスケーラー連携は後続フェーズで扱う。

## 9. 成功条件

- 同じ入力と設定から同じ出力が得られる。
- 主要パラメータをYAMLで保存できる。
- 2000px級入力を2x/3x/4x/6x/8xにできる。
- 斜め線・円弧・建物輪郭に明確な階段ジャギが出ない。
- 線画マスク抽出失敗時に、デバッグ画像で原因を確認できる。
- 外部アップスケーラーなしで開発・テスト・MVP出力ができる。

## 10. 用語

- `line_prob`: 黒線らしさを0.0〜1.0で表した低解像度マップ
- `line_mask`: 線画領域の二値マスク
- `line_alpha_hr`: 高解像度線アルファ
- `tone_source`: 後続フェーズで使う、入力から線を軽く除去・白方向へ持ち上げた階調素材
- `tone_hr`: 後続フェーズで使う、高解像度階調素材
- `final`: 合成後の最終画像
- `SDF`: Signed Distance Field。線領域の内外距離を持つ距離場
