# Security policy

Security fixes are provided for the latest release. Do not disclose a suspected
vulnerability in a public issue. Use GitHub's private **Report a vulnerability**
form in the repository Security tab. If that form is not available, contact a
maintainer privately before publishing technical details.

Include the affected version, Windows version, reproduction steps, and the
security impact. Never attach private images, API tokens, certificates, or
code-signing keys.

Release builds are produced only by the repository's GitHub-hosted workflow.
Code-signing private keys are held by SignPath and are never stored in this
repository or in GitHub Actions.
