# Privacy policy

723 Manga Upscaler processes images locally. It has no telemetry, analytics,
advertising, account system, or automatic update function. It does not send
images, settings, or usage information to the project maintainers.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

If a user explicitly configures an optional external upscaler or Potrace,
723 Manga Upscaler invokes that separately installed command-line program. Any
network behavior and privacy terms of that external program are controlled by
its provider. Those optional tools are not included in the distributed EXE.

The application does not install services or modify system configuration.
Uninstallation consists of deleting `723MangaUpscaler.exe` and any output files
the user no longer needs.
